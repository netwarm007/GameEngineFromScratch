## Verified boundary

- Viewer owns its ImGui context through `GuiContext`; the context and its CPU
  font atlas outlive application cleanup. Repeated initialization cannot
  silently replace an existing context.
- Enabled native desktop platform GUI setup occurs after graphics/view setup
  and before module initialization. Window creation alone does not bind ImGui;
  Cocoa binds the final content view installed by its graphics backend.
- Graphics managers own their ImGui renderer initialization and shutdown.
  Initialization errors propagate, an already bound renderer is rejected
  without replacement, and uninitialized or already finalized renderers are
  not shut down again.
- Metal RHI native resource initialization no longer requires an ImGui
  context. Its graphics manager owns the ImGui Metal backend and waits for
  retained render/compute submissions before releasing UI resources.
- Draw passes release UI icons and debug texture views while the renderer,
  descriptor pool and native graphics resources are still available.
  D3D12 resets its UI descriptor slot pool after renderer shutdown.

This accepts the selected stage C ownership boundary described in the
[modularization roadmap](../architecture/modularization-roadmap.md), not a
general UI rewrite or exhaustive backend fault-recovery implementation.

## Limitations

The screenshot samples verify rendered visibility and containment, not every
interactive input path, font glyph, floating multi-viewport teardown or the
complete Splash animation. Saved-layout, viewport-origin and framebuffer-scale
coverage here is from the headless layout regression rather than new native
interactive sessions. Viewer capture scripts are best-effort: Linux capture
terminates Viewer after capture, and macOS capture success does not by itself
prove normal Viewer process exit.

Native failure coverage remains selected, not exhaustive driver allocation
failure, device loss, concurrent initialization or full module-graph restart.
Metal failure after submitted native GPU work was not independently injected.
SDL/Android GUI platform ownership was not migrated. Windows OpenGL received
only a local compile check, not native runtime acceptance; D2D, Vulkan,
WebAssembly and other unlisted configurations were not verified.
