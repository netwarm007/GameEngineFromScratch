## Limitations

The pipeline verifies the configured platform builds, tests, material cooking,
and screenshot/regression steps. It does not exercise the CMake Tools extension
inside an interactive VS Code session or every launch configuration. Android,
WebAssembly, and other unlisted configurations are not verified by this
pipeline. This record verifies only the source revision above.
