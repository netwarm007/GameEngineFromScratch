This verifies the M2.3 owned startup composition in the
[runtime RHI roadmap](../architecture/runtime-rhi-switching-roadmap.md):
typed, explicit per-backend factories; owned application/graphics/pipeline
composition; retention of every included implementation; explicit absent and
invalid backend errors without fallback; render conventions derived from the
selected backend; availability probing that reports compiled inclusion plus
Vulkan loader evidence. It does not establish application runtime selection
(M2.4/M2.5) or native startup of every backend from one executable (M2.6).
Viewer and Billiard keep their existing compile-time startup paths.

## Failed-construction cleanup fix included

The first Windows quick run of the composition regression segfaulted while
destroying the first uninitialized D3D12 composition. Diagnosis:
`D3d12GraphicsManager::m_PerFrameConstantBuffers` and
`m_PerBatchConstantBuffers` (`std::array<D3d12RHI::ConstantBuffer, 2>`) lacked
`{}` value-initialization, so the destructor's `SafeRelease` dereferenced
indeterminate `buffer` pointers. Native Windows runs never exposed this
because `Initialize()` creates the buffers before destruction; Linux/macOS do
not compile D3D12. Both arrays are now value-initialized, matching the
adjacent `m_LightBuffers{}`/`m_ShadowBuffers{}` members. The composition
regression is the failing-without-fix demonstration; temporary diagnostic
markers used to locate the crash were removed before acceptance.

## Limitations

- Application CLI wiring is not in this revision; runtime selection is not
  advertised. `--rhi`/`--list-rhi` reach applications only at M2.4/M2.5.
- Availability probes report compiled inclusion and Vulkan loader evidence;
  they do not create devices. `ReadyForInitialization` is not successful
  initialization.
- Native evidence of selecting each backend from one executable, and Windows
  native Vulkan/OpenGL startup coverage, remain M2.4-M2.6 scope.
- The composition's single active Vulkan dispatch context still rejects a
  second simultaneous Vulkan RHI; multi-backend simultaneous rendering is
  outside the first-release contract.
