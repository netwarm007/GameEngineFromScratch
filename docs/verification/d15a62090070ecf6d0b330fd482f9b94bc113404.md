## Fix chain (real-machine findings → resolution)

| Finding | Symptom | Root cause | Fix |
| --- | --- | --- | --- |
| 1 | Recovery fails when the window was already destroyed by the failed switch | `recreateWindow` did not account for an absent window | `recreateWindow \|= windowAbsent` (`becc14db`) |
| 2 | "Switch complete" markers seemingly missing | Evidence artifact: `Stop-Process -Force` dropped unflushed `cout`; framebuffer was non-zero | Retracted (no code change) |
| 3 | Failure dialog / progress modal never shown | Switch + recovery complete synchronously inside one frame boundary; per-frame edge detection never observes switching, and `LastError` was cleared | Controller `ConsumeSwitchFailure` event queue consumed by the GUI (`cb3a69a1`) |
| 5 | Backend menu vanished after a switch; failure dialog unreachable | `SetRhiSelectionProvider` bound only at startup; the fresh `GraphicsManager`/`GuiSubPass` had a null provider, and `OverlayPass` captures the provider at construction (before the post-switch re-bind) | Re-bind provider after `graphicsManager` reassignment (`3d4cdb1d`) **and** refresh `m_pRhiSelection` from the manager each `GuiSubPass::Draw` (`82323ef8`) |
| 4 | Recovered OpenGL window stayed gray (class background brush); frame Tick stalled | Recreated window class lacked `CS_OWNDC`; WGL `SwapBuffers` returned TRUE on a shared DC but presented nothing | `CS_OWNDC` on the main window class (`ad69a880`); also refresh the stale main-viewport `WglViewportData` on activation |

## Known limitations (non-blocking, recorded)

- Vulkan availability probe checks the loader only (a device missing
  `maintenance1` still shows "ready"); deep probe is a future enhancement.
- The `GEFS_SCREENSHOT_PATH` gate is assembled by the startup backend and does
  not follow switches (architecture limitation).
- The progress modal is inherently brief because switching completes
  synchronously within one frame boundary; it was not separately captured.
- Vulkan on WSL uses the lavapipe software ICD (no hardware ICD); recorded as a
  known limitation while still exercising the Vulkan functional matrix.
