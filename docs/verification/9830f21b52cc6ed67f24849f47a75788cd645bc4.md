## Lifecycle change and focused regression

RuntimeModuleGroup accepts an optional callback invoked after a module reports
an initialization error, but before reverse cleanup of previously initialized
modules. BaseApplication supplies its existing WaitForGraphicsIdle hook.
This closes the gap where GPU work submitted during initialization could still
reference resources released by rollback before Initialize returned.

The callback runs even when the first module fails. It does not run on successful
initialization or rejection of an already initialized group. Existing standalone
module-group callers retain immediate reverse rollback without requiring a
graphics dependency. Error codes, retained registrations for retry, and cleanup
of only successfully initialized modules remain unchanged. The failing module
is still responsible for its own partial-initialization cleanup.

ApplicationLifetimeTest now models GPU submissions during initialization at
each failing module position. It verifies synchronization before rollback,
live backend/window resources during cleanup, unchanged errors, no ticks after
failure, retry to success, no rollback synchronization on success or repeated
initialization rejection, and exact-once module cleanup on final shutdown.
The new tests failed against the previous production implementation, including
the assertion that pending GPU work must finish before module cleanup.

After the fix and again after rebasing, the local Windows Debug
ApplicationLifetimeTest, RenderServicesTest, and RuntimeModuleLifecycleTest
passed using the existing session-local CMake harness. Full native application
builds and exit checks used the exact-revision CI jobs above.

## Limitations

Pending GPU work during failed initialization is modeled by the application
regression, not injected into a real failing native GPU initialization.
The native CI applications exercise successful initialization and clean exit.
Device/context/allocation failure injection, cleanup inside a failing module,
exception-based initialization failure, and ImGui ownership are not redesigned
or comprehensively verified here.

Windows OpenGL, D2D, Vulkan, Android, SDL, WebAssembly, and other unlisted
configurations were not runtime-verified. Android remains disabled in CircleCI.
This record verifies only the full source revision above, not the
documentation-only commit adding this file or any later merge. No pull request
is required for this intermediate checkpoint.
