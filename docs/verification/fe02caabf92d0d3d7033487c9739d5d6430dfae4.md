## Focused regression and local verification

RenderServicesTest drives the production GraphicsManager::Tick to
GuiSubPass::Draw path with a recording backend. It repeatedly rebuilds resources
for one Scene, deliberately reusing shadow/skybox handles and array sizes.
The checks cover:

- Revision publication to every in-flight frame, including a rebuild starting
  from a nonzero frame index, and revision clearing at teardown.
- Releasing and replacing all 21 debug views (three shadow layers and 18
  skybox face/mip views) for each of two same-Scene resets.
- Exactly-once retirement and stable live-view counts.
- Cache reuse across frame rotation when resources have not changed, including
  subsequent frames after a rebuild.

Before the production fix, the new regression failed on missing revision
propagation and retained same-Scene views. After the fix, Windows Debug builds
of RenderServicesTest, GuiSubPassLayoutTest, OpenGLRHI and D3dRHI succeeded.
The final focused local run was:

```text
ctest --test-dir build-review-a -C Debug -L fast -R "TEST_(RenderServicesTest|GuiSubPassLayoutTest)$" --output-on-failure
2/2 passed
```

Existing scene-identity invalidation, layout, saved-settings and icon ownership
checks remain intact. `git diff --check` passed.

## Remaining limitations

- The forced same-Scene/identical-handle case is deterministic recording-backend
  coverage. Native scene-cycle captures exercise real resource retirement and
  UI rendering, but do not force or prove GL name reuse for the same Scene.
- Linux is software OpenGL, not hardware-driver validation. Its Viewer capture
  script terminates the application after capture; it does not prove normal
  Viewer shutdown. Windows/macOS scene-cycle and all Billiard steps enforce
  successful process exit. Ordinary macOS Viewer capture is best-effort; its
  actual PNG was checked rather than inferred from the step result.
- Screenshots do not certify every debug thumbnail, native input/focus paths,
  performance, animation/pixel equivalence, or every light/cube-face
  configuration. Windows captures show low frame rates and hover tooltips.
- Android is disabled. Vulkan, GLES, unlisted devices/backends and future merge
  revisions are not verified here.
