## Iteration history (root causes found and fixed)

Pipelines 1129–1137 exposed and fixed, in order: test subclasses relying on
removed default constructors (RayTracingTest, GraphicsWindowTest, ImGuiTest);
ObjC/C++ mangling divergence for the Metal drawable provider (type-erased to
`void*`); GLX platform library lacking the GL loader (`glXWaitGL` instead of
`glFinish`); the Vulkan session factory binding the concrete pipeline
manager; root registration bypassing the host's borrowed manager pointers
(SDL resize segfault); `root.Tick` bypassing the OpenGL buffer swap and the
Cocoa Metal headless pacing (`IRenderBackend::PresentFrame`, pacing moved to
`ProcessEvents`); the persistent D3D12 RHI keeping a stale swapchain frame
index across reconstruction; renderer ImGui shutdown destroying platform
windows (GUI platform must always rebind) with zero first-DeltaTime guards
(OSX/Win32, matching SDL2); freed session-module address reuse tripping
duplicate registration (`BindSessionManagers`); and window-teardown resize
messages routing through freed manager pointers (bind null before
retirement). Pipeline 1138 is the first fully green run of the complete M3
scope on all three platforms.

## Known limitations carried forward

- XCB ImGui parity (Linux XCB-only host) remains the tracked M2.4 follow-on;
  Linux keeps the SDL OpenGL host.
- Cross-backend switching, held-input/queued-event reconciliation, and
  minimized-window/quit-during-switch behavior are M4 scope.
- Native partial-init failure injection is not claimed; failure recovery is
  covered headlessly on the production root primitives plus the native
  error-path smoke.
