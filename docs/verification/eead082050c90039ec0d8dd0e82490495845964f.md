Tests included physics/scene integration without an application, including
scene replacement and retry when a revision has no scene. Each platform passed
the real Billiard shot and collision regression. The exact-revision images were
inspected: the table and ball cluster are inside the main viewport, the docked
panels are visible, and the ball positions reflect the shot. The Windows image
has a mouse-hover texture tooltip that does not obscure the ball cluster.

Movement is measured in scene units; required minima are 0.1 and 0.01.
Windows CI does not verify Billiard's default OpenGL backend because its host
cannot initialize WGL. The local Windows OpenGL regression also passed with
the table and panels visible. These results apply only to the tested
configurations and captured scene, not every OS version or full rendering
correctness.
