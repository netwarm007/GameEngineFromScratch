## Limitations

- Wall clocks are warm-cache numbers; cold dependency-cache runs add build
  time upstream of build_windows but not to matrix slots (they consume the
  workspace).
- The Mesa save_cache is keyed by version string, not content hash; a
  mesa-dist-win re-release under the same tag would require bumping the key.
- vulkan-sdk is still choco-installed per slot (retry-guarded); side-by-side
  caching remains a follow-up in the budget design.
