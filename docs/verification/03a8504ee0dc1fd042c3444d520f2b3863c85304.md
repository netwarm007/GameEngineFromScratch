## Scope

Foundation and `BlockAllocator` fixes from the
[memory allocator roadmap](../architecture/memory-allocator-roadmap.md):
aligned page allocation, configuration validation, lazy block carving, null
and out-of-memory handling, invalid and double-free detection, and
`MemoryManager` statistics and thread safety. The test also ran locally
under ASan/UBSan on Linux (Debug-like and optimized flags).

## Limitations

- The allocators are not used by other engine modules yet, so no rendering
  backend or screenshot behavior was exercised or changed.
- Free-pointer validation is on by default only in `_DEBUG` builds; the tests
  enable it explicitly, so the default Release setting is covered only for
  allocation paths.
- Thread safety applies to `MemoryManager`; `BlockAllocator` is single-threaded.
- `StackAllocator` is still an unimplemented shell (checkpoint M2).
