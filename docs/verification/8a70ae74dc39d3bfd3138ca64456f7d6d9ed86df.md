## Limitations

- Physical Retina and mixed-DPI Cocoa viewport movement were not tested.
- Windows Vulkan WSI was not run; the Windows job validates its configured
  OpenGL/D3D12 build and tests, not Vulkan presentation.
- The Vulkan GUI descriptor pool retains its existing fixed capacity for
  simultaneously displayed textures; this change defers descriptors for
  registered textures that are not drawn.
- Linux uses lavapipe/Xvfb for Vulkan application captures. These results do
  not establish hardware-specific behavior or untested platforms/backends.
