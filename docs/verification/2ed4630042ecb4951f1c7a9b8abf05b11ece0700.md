## Boundary and focused regression

The SceneCamera library prepares camera matrices and position from an explicit
scene, render canvas dimensions, and projection convention. Its headless test
links only SceneCamera, SceneGraph, Common, and scene identity dependencies,
without Manager, Application implementation, RHI, ImGui, asset IO, or decoders.
GraphicsManager consumes the current frame's scene snapshot rather than
looking up the camera scene through Application.

The camera regression checks:

- Scene camera translation, runtime movement, look-at target, and right-handed
  view coordinates.
- OpenGL [-1, 1] and D3D/Metal [0, 1] near/far depth mapping.
- Canvas resize/aspect behavior without changing vertical FOV.
- Default camera view, clipping planes, and matching shader camera position
  when replacing a scene that had an explicit camera.
- Invalid canvas dimensions, unresolved camera references, non-finite FOV,
  and reversed clipping planes, without partial output publication.

Temporarily selecting the D3D/Metal projection for OpenGL made the headless
regression fail for both explicit and default cameras. The production selection
was restored and the test passed.

## Limitations

This checkpoint extracts perspective camera preparation only. Lighting
preparation, RHI ownership, platform window adaptation, and ImGui lifecycle
remain in their existing layers. It does not introduce orthographic rendering
or validate every malformed camera pose. Invalid projection inputs are reported
and skip rendering that frame rather than publishing partial camera data.

Windows OpenGL, Android, WebAssembly, Vulkan, CUDA, and other unlisted
configurations are not verified by this pipeline. Screenshots and the fixed shot
do not establish full rendering or physics correctness.
This record verifies only the source revision above, not a subsequent merge or
the documentation-only commit adding this file.
