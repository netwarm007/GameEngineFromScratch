## Observations

- The weekly cache-period key files (`/tmp/cache-period.txt`, `C:/cache-period.txt`)
  were accepted by `restore_cache`/`save_cache` on all three platforms.
- On this non-`master` branch the source and ccache caches were restored only;
  saving is limited to `master`.
- Windows and Linux saved Release dependency caches. This run had no matching
  cache, so the restore-and-skip path for the Release dependencies was not
  exercised here and no time saving is established by this record.

## Limitations

Timing improvements are not measured by this record. Android remains disabled;
Emscripten/WebAssembly, FreeBSD, CUDA and OptiX are not accepted by this
record.
