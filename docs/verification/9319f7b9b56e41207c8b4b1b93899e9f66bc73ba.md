## Focused local verification

Windows Debug builds used the merged source, installed MSVC/Windows SDK tools
and the existing locked dependency revisions, prepared only in A's worktree.
No submodule pins or source files were changed to make the tests pass.

The engine configuration used `CMAKE_EXPORT_COMPILE_COMMANDS=ON`,
`OPENGL_RHI_DEBUG=ON`, `D3D12_RHI_DEBUG=ON` and `BILLIARD_USE_D3D12=ON`.
Viewer and Billiard production executables built successfully.

The final focused CTest run passed all 11 selected tests:
BilliardGameLogicTest, ViewerLogicTest, InputManagerTest,
ApplicationLifetimeTest, GuiSubPassLayoutTest, RenderServicesTest,
PhysicsSceneIntegrationTest, ShadowShaderCompatibility,
D3d12Initialization, D3d12GuiTexture and RuntimeModuleLifecycleTest.
The standalone GeomMath C++ and ISPC tests also passed, including the shared
point-shadow matrix checks. The inactive legacy Billiard factory compiled
with the real dependency headers.

An initial integration-test run could not find scene assets because the local
build was outside the repository ancestry. Staging the unchanged splash and
billiard scene files under the build's `Asset/Scene` resolved that packaging
issue, after which the complete focused selection passed. The local glslang
install also needed its upstream Windows `copy_if_different` compatibility
alias from `glslang.exe` to `glslangValidator.exe`.

## Limitations

Synthetic input does not establish native OS event delivery or exhaustive
ImGui focus/capture behavior. The legacy factory is compile-checked, not wired
into the current native executable. Existing valid window-dimension
preconditions remain.

Linux diagnostics identify Mesa llvmpipe, not hardware OpenGL. Windows/Linux
red shadow thumbnails and Metal white/gray thumbnails remain different.
Animation timing and orientation differ between captures. These images do not
establish pixel parity, exhaustive point-light/cube-face coverage, or acceptable
performance; Windows screenshots in particular show low frame rates.
Optional terrain tiles use the existing fallback texture, and an unused Metal
RAYTRACE pipeline remains unavailable.

Android is disabled. Vulkan, GLES, unlisted devices/backends and future merge
revisions are not accepted by this record. No PR was created and this branch
was not merged into master.

is not a newly tested source revision and does not supersede other revisions'
records.
