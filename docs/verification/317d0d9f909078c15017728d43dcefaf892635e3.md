# CI default full scope verification

CircleCI [pipeline 997](https://app.circleci.com/pipelines/github/netwarm007/GameEngineFromScratch/997)
passed the full `build-and-test` workflow for revision
`317d0d9f909078c15017728d43dcefaf892635e3`. It was started by a plain branch
push with no API call or token, so it shows that the default `run_full: true`
keeps the previous push behavior. Revision `13586adb…` (see its own record)
had the opposite default and is superseded by this change.

| Platform | Backend | Job | Duration | Result |
| --- | --- | --- | --- | --- |
| Windows | D3D12 | 4549 | 2002 s | Build, tests, screenshots, and Billiard regression passed |
| Linux | OpenGL | 4548 | 433 s | Build, tests, screenshots, Billiard regression, and coverage passed |

## Artifact observations

Viewer and Billiard screenshots from all three jobs were inspected. Panels are
docked, visible, and not overlapping, and the scene renders in the Viewer
panel. As before, Windows shows a mouse-hover UV tooltip at low frame rate, and
the shadow-map preview colour differs on macOS; neither was investigated.

## Limitations

- Windows took 2002 s versus 1235 s in pipeline 992; the cause was not
  investigated (it is not cache-related, as Windows has no ccache).
- Quick scope (`run_full: false`) was not re-run for this revision; it was
  verified on `13586adb…` (pipeline 983) with the previous default.
- Android is disabled and was not tested. Vulkan was not tested.
