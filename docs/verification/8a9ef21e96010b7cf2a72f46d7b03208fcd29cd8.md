## Changes exercised

OpenGL now builds the point-shadow geometry shader and supplies six cube-face
matrices. Metal uses six vertex instances with a layered depth attachment,
explicit triangle topology, and vertex/fragment shadow constants. Both app
shader libraries include the new Metal vertex function. Native D3D12 retains
its geometry-shader path and viewport convention through the shared matrix
helper. All three paths write radial world-space distance and reconstruct it
with `POINT_SHADOW_FAR_PLANE`. Missing required pipelines no longer silently
select an unrelated pipeline.

The changes also reset OpenGL depth writes before clearing the main pass,
removing its dependency on a preceding shadow pass to establish that state.

## Focused local checks and limitations

Portable C++ math and pipeline-error checks passed locally, as did GLSL stage
linking, MSL generation, and the actual shader asset target. A software OpenGL
rendering probe using the generated production shadow stages checked radial
depth on six faces for two translated lights and independent cube-array
indices. The production sampling function returned visibility
`1.0, 0.12, 1.0, 0.12` for unoccluded, occluded, off-occluder, and second-light
cases. Restoring either the old fragment-position depth calculation or the
old sampling scale made that probe fail. This local harness is a session
artifact, not a new CI test.

Linux diagnostics identify Mesa llvmpipe; hardware OpenGL was not tested.
Native Metal and D3D12 screenshots do not exhaustively verify every cube face
or multiple point lights. The earlier controlled floating-cube on/off scene
was not rerun on native backends for this revision.

The Metal Billiard log explicitly reports unavailable, unused RAYTRACE and
cube-map debug pipelines. They are not consumed by these scene captures;
this record does not verify those features. Disabled Android, other rendering
backends, and untested devices are not covered. The separate no-shadow-pass
OpenGL state correction has compilation coverage but was not captured in a
native all-shadows-disabled scene in this pipeline.

This record verifies only the tested source revision, not a later
documentation commit or a merge revision.
